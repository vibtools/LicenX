# SDK Documentation Portal

Source: `SDK/x_license_python/docs/README.md`

This portal links the English and Bangla integration guides and provides a quick-start example plus a module responsibility map. It is the entry point for the existing user documentation; this new `SDK feature/` directory is the source-level, file-by-file companion.

The quick-start path depends on an actual application version being supplied and a valid trusted public key. Consult [configuration](config.md) and [transport](server.md) for those requirements; do not copy minimum-version policy into the client version field.
