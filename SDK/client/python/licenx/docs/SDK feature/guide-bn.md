# বাংলা Integration Guide

Source: `SDK/x_license_python/docs/GUIDE_BN.md`

এই ফাইলটি Python SDK-র পূর্ণাঙ্গ বাংলা developer integration guide। এতে SDK ব্যবহার, configuration ও license lifecycle-এর জন্য বাংলা ভাষায় ব্যাখ্যা দেওয়া আছে; ইংরেজি নির্দেশিকার সঙ্গে এটি একই documentation set-এর অংশ।

Implementation-এর সঙ্গে কোনো বর্ণনা না মিললে current source অনুসরণ করুন। বিশেষ করে trusted public key নিরাপদভাবে provision করতে হবে, প্রকৃত client `app_version` দিতে হবে, remote server-এর জন্য HTTPS ব্যবহার করতে হবে, এবং offline grace-কে শুধু চলমান session-এর heartbeat policy হিসেবে বুঝতে হবে। কোনো guide text hosted বা production verification-এর প্রমাণ নয়।
