## Reporting a Vulnerability

We take the security and cryptographic integrity of **LicenX** seriously. If you discover a security vulnerability or exploit in the cryptographic signature verification, hardware locking algorithm, or authentication workflows, please do **NOT** open a public issue on GitHub.

Instead, please responsibly disclose it by emailing:
**teamdarkdevil24@gmail.com**

Please provide:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept (PoC) code to reproduce the issue.
- Your recommended remediation or patch (if available).

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure and security advisory.
